Что такое WARP и зачем это нужно
Если ваш VPS-сервер ранее находился в плохих руках — использовался для рассылки спама, DDoS-атак или других злоупотреблений — его IP-адрес мог попасть в черные списки (Spamhaus, AbuseIPDB, Cloudflare Radar). Это приводит к тому, что сайты и сервисы блокируют ваши запросы.

Cloudflare WARP — это бесплатный VPN-туннель от Cloudflare. При его активации весь исходящий трафик вашего сервера будет идти через чистые IP-адреса Cloudflare, что автоматически решает проблему грязной репутации IP. Ваши клиенты смогут свободно открывать сайты (Google, YouTube, Telegram) без блокировок.

Установить WARP на сервер

Автоматически выполняет команду установки warp-cli от Cloudflare через API панели. Требует root-доступа.

Режим работы WARP

Proxy — только конкретные приложения. Full — весь трафик сервера через Cloudflare.

Проверить репутацию IP

Запрашивает внешние сервисы для проверки текущей репутации IP-адреса вашего VPS.

Что такое WASM-плагины морфинга

WASM-плагины позволяют на лету изменять поведение рукопожатия (handshake) протокола Hidekey. Это позволяет сбить с толку системы глубокой инспекции пакетов (ТСПУ/DPI), которые используют нейросетевые поведенческие детекторы для выявления VPN-трафика. Каждый плагин — это скомпилированный WebAssembly-модуль, загружаемый без перезапуска ядра.
