# hide-ui-and-super-box-core

# 🛡️ Hide-UI: Премиальная Веб-Панель Управления для VPN-Ядра Hidekey (Super Box)

[!TODO: Добавьте скриншоты вашей панели здесь для визуального вау-эффекта!]

**Hide-UI** — это встроенная, легковесная и эстетичная веб-панель управления для асинхронного VPN-ядра **Super Box (протокол Hidekey)**. 

Интерфейс панели разработан в благородном темном стиле с элементами Glassmorphism, вдохновленным дизайном современной панели 3x-ui, но полностью переписан с нуля для работы в связке с криптографическим anti-DPI ядром на Rust.

> [!IMPORTANT]
> **Концепция Single-Binary (Все в одном бинарнике):**
> Панель не требует установки внешних веб-серверов (Nginx/Apache), сред выполнения (Node.js/Python) или отдельных СУБД (MySQL/PostgreSQL). Бэкенд написан на чистом Rust (Axum + Hyper), файлы фронтенда полностью вшиваются в исполняемый файл на этапе компиляции, а настройки сохраняются в высокопроизводительную встроенную базу данных `sled`. Запуск сервера одной командой поднимает и VPN-туннель, и панель управления!

## 🚀 Ключевые возможности Hide-UI

### 1. 🕵️ Сверхсекретность и Защита от Активного Сканирования ТСПУ
*   **Скрытый URL-путь («Лапша»):** Панель полностью скрыта от посторонних глаз за уникальным случайным префиксом пути (например, `https://your-server-ip:8082/6jzoprp0c8gz.../`). Секретный префикс генерируется при первом запуске или настраивается вручную.
*   **Decoy 404 (Ложное отрицание):** Запросы на корень сервера `/` или любые неавторизованные пути возвращают стандартную пустую страницу `404 Not Found`. Для внешних DPI-сканеров и провайдерских фильтров ваш хост выглядит как неактивный или пустой веб-сервер.
*   **Автоматический HTTPS по умолчанию:** При первом запуске встроенная библиотека `rcgen` генерирует уникальную пару ключей и самоподписанный TLS-сертификат сроком действия на **10 лет**, защищая все передаваемые учетные данные от перехвата в сети.

### 2. 📊 Живая телеметрия ресурсов сервера в реальном времени
*   **Мониторинг без оверхеда:** Метрики считываются бэкендом на Rust напрямую из системных файлов ядра Linux (`/proc/stat`, `/proc/meminfo`, `/proc/loadavg` и `/proc/net/tcp`) каждые 2 секунды.
*   **Анимированные SVG-диаграммы:** Динамическое отображение нагрузки на процессор (CPU), оперативную память (RAM), Swap-файл подкачки и заполненность жесткого диска.
*   **Анализ трафика:** Отображение текущей скорости скачивания и отдачи в реальном времени, общего количества активных сокетов и суммарного потребленного трафика.

### 3. 👥 Интеллектуальный CRUD-менеджер клиентов (Peer Map)
*   **Управление пирами в один клик:** Таблица зарегистрированных пиров с тумблерами мгновенного включения/отключения ключей доступа в оперативной памяти ядра.
*   **Полиморфный генератор ключей:** Автоматическая генерация клиентских ссылок формата `hidekey://` с дизайном быстрого копирования в буфер обмена или резервными текстовыми полями, автоматически выделяющими весь текст по клику.
*   **Детерминированный учет трафика:** Интеллектуальное распределение сетевой статистики по каждому конкретному пользователю на основе криптографического хеша его идентификатора.

### 4. 🎛️ Настройки полиморфизма и DPI-обхода
*   Управление стратегиями шифрования трафика и маскировки под WebRTC аудиопотоки (эмуляция Opus RTP заголовков мессенджеров Telegram/Discord).
*   Внедрение случайного маскировочного шума (Junk-байтов) случайной длины перед рукопожатием (аналог технологии Amnezia WireGuard) для обхода DPI.
*   Активация сетевого ускорения ядра Linux **TCP BBR** одной кнопкой в настройках панели.

```text
super-box/

│   │   └── handlers.rs    # REST API обработчики, сбор системных метрик /proc
│   └── main.rs            # CLI-команды ядра (set-admin, set-port, get-admin)
```

**Super Box** — это высокопроизводительное, легковесное VPN-ядро, написанное на чистом асинхронном Rust (`tokio`). Разработано с нуля для обхода самых современных систем глубокого анализа пакетов (DPI / ТСПУ) с использованием уникального полиморфного протокола **Hidekey**.
В отличие от традиционных VPN, страдающих от "устаревшего наследия" (zero-legacy концепция), Super Box не имитирует стандартные веб-протоколы (вроде HTTPS), а маскирует защищенный трафик под легитимные RTP/WebRTC голосовые вызовы мессенджеров и хаотичный шум.

## 📐 Архитектура сетевого стека
Трафик перехватывается на уровне TUN-интерфейса и упаковывается в зашифрованные крипто-кадры:
```text
 ┌──────────────────────────────────────────────────────────────────┐
 │                           SUPER BOX                              │
 │                                                                  │
 │  ┌─────────────┐    ┌─────────────┐    ┌──────────────────────┐  │
 │  │  inbound.rs  │───▶│  router.rs  │───▶│    outbound.rs       │  │
 │  │  (SOCKS5 /   │    │  (routing)  │    │  (Hidekey Connector /│  │
 │  │  TUN Layer)  │    └─────────────┘    │   Server Listener)   │  │
 │  └─────────────┘                       └──────────────────────┘  │
 │         ▲                                         │              │
 │         │          config.rs (Arc<Config>)        │              │
 │         └─────────────────────────────────────────┘              │
 └──────────────────────────────────────────────────────────────────┘
```
⚡ Технические особенности ядра
1. 🔑 Бескомпромиссная криптография (Zero-Legacy & PFS)
Perfect Forward Secrecy (PFS): Каждая сессия генерирует эфемерные пары ключей X25519 (Diffie-Hellman). Даже если мастер-ключ будет скомпрометирован, прошлый трафик расшифровать невозможно.
BLAKE3 Сверхскорость: Для генерации сессионных ключей (KDF) и вычисления имитозащиты (MAC) используется хеш-функция BLAKE3.
Аутентификация Constant-Time: Сравнение контрольных сумм MAC реализовано константным XOR-циклом на уровне байт, полностью исключая атаки по времени (Timing Attacks) без использования тяжелых внешних библиотек.
Сверхнадежный шифр AEAD: Все данные внутри туннеля шифруются с помощью ChaCha20-Poly1305 со случайными не повторяющимися Nonce.
2. 🕵️ Инновационная маскировка DPI (Amnezia-style & RTP)
Двусторонний мусор перед рукопожатием (Handshake Junk): Перед началом обмена ключами клиент отправляет случайный блок крипто-шума длиной от 16 до 128 байт (размер меняется каждую сессию). Сервер отвечает аналогичным случайным шумом. Это делает сетевой размер пакетов первого контакта хаотичным, лишая DPI возможности зацепиться за сигнатуру длины пакета.
Тихий сброс (Silent Connection Drop): Если клиент присылает неверный MAC-код в Challenge, сервер мгновенно и тихо закрывает TCP-соединение, не возвращая ни одного байта. Для DPI-сканеров хост выглядит абсолютно мертвым.
Стеганография WebRTC (RFC 3550 RTP): После рукопожатия шифрованные пакеты упаковываются в 12-байтовые Opus RTP-заголовки. Для ТСПУ это выглядит как обычный голосовой вызов в Discord, Telegram или Viber.
3. 🌐 Умная интеграция с ОС (Windows & Linux)
Discover Gateway (Bypass TUN): На Windows клиент автоматически определяет ваш настоящий физический шлюз и использует сокетный вызов IP_UNICAST_IF, заставляя трафик к VPN-серверу лететь напрямую через физическую карту, исключая бесконечную маршрутизацию через TUN.
DNS Interceptor (Защита от утечек): Ядро перехватывает системный UDP DNS (порт 53), оборачивает запросы в TCP и пускает через защищенный туннель Hidekey на серверный systemd-resolved. В случае сбоя сети плавно срабатывает безопасный UDP-fallback через физический адаптер.
📦 Формат пакета на физическом уровне (Wire Protocol)
Этап 1: Рукопожатие с шумом
Клиент ➔ Сервер: [2 байта длины мусора J] + [J байт случайного шума] + [76 байт Challenge (12B nonce + 32B pub_key + 32B MAC)]
Сервер ➔ Клиент: [2 байта длины мусора S] + [S байт случайного шума] + [76 байт Response (12B nonce + 32B pub_key + 32B MAC)]
Этап 2: Передача данных (Data Packet)
[2 байта длины кадра] + [12 байт RTP заголовка] + [ChaCha20-Poly1305 Ciphertext + 16B Auth Tag]

🛠 Кросс-платформенная сборка
Ядро спроектировано для работы на любых устройствах:

Сборка под Windows (x64)
bash


cargo build --release
Для работы TUN на Windows используется драйвер wintun.dll (в комплекте).

Сборка статического бинарника для Linux (Musl)
Сборка полностью автономного файла без зависимости от glibc для Ubuntu/Debian/Alpine:

bash


rustup target add x86_64-unknown-linux-musl
cargo build --release --target x86_64-unknown-linux-musl
(Результат сборки находится в target/x86_64-unknown-linux-musl/release/super_box)

Портирование под Роутеры (OpenWrt)
Скрипты кросс-компиляции и Makefiles для упаковки в .ipk пакет находятся в директории openwrt/. Поддерживает архитектуры MIPS, MIPSEL, ARM64 и x86_64.

Портирование под Смартфоны (Android JNI)
Исходные коды на Rust JNI (jni_wrapper.rs) и шаблон VPN-сервиса на Kotlin (MyVpnService.kt) лежат в директории android/. Позволяет скомпилировать .so библиотеку с помощью Android NDK.
